Do It

A week-at-a-glance to-do list. Repeating chores show up on their own, one-offs go on a day or in the “anytime this week” tray, and everything is colour-coded by category.

  1. Create an Airtable base with two tables: Templates and Log. (Already using Do It v4? Just reuse the same base.)
  2. Templates: Title (text), Category (single select), Days (multiple select Mon–Sun), Time (text), Active (checkbox), Repeat (text).
  3. Log: Title, Category, Type, TemplateId, Date, Time, Status, CompletedAt, Notes, CalendarEventId (all text).
  4. Create a Personal Access Token at airtable.com/create/tokens with data.records:read and data.records:write on that base. Add schema.bases:read + schema.bases:write too and the app will add the Repeat field for you.
